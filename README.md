# Pong Game – Lua & LÖVE 2D

## About the Project
A classic two-player Pong game developed using **Lua** and the **LÖVE 2D framework**.

Two players control paddles and try to hit the ball past their opponent. The first player to reach 5 points wins the game.

## Features
- Two-player gameplay.
- Smooth paddle movement.
- Ball movement and collision detection.
- Ball bouncing off the top and bottom boundaries.
- Score tracking.
- Game Over screen displaying the winner.
- Restart the game using the Enter key.

## Controls

| Player | Move Up | Move Down |
|---|---|---|
| Player 1 (Left) | W | S |
| Player 2 (Right) | Up Arrow | Down Arrow |

## Technologies Used
- Lua
- LÖVE 2D

## How to Run
1. Install [LÖVE 2D](https://love2d.org/).
2. Download or clone this repository.
3. Open a terminal inside the project folder.
4. Run the game using:

```bash
love .
```
